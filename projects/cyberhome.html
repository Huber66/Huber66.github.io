WHY

为什么做一个赛博家

让“有人在”和“被记得”，
成为可以走进的日常。

项目的出发点是一个很日常的愿望：下班回到住处，或者在深夜打开手机时，能走进一个熟悉、有生活气息的地方，看看在意的角色，知道他们刚刚经历了什么。

CyberHome 希望把这种感受放进一个可以亲手创造的家庭世界。用户设定角色的性格与习惯、布置空间、安排谁与谁相遇；角色结合人设、所在房间和记忆参与互动，日常事件逐渐积累成这个家的共同经历。

创造带来投入，相遇带来故事，记忆为下一次互动提供延续。我们希望用户愿意回来，是因为惦记这里的人和故事。

希望陪伴的三个时刻

想创造的时候
布置一个自己的小世界，设定有性格的角色，看看他们在同一空间会发生怎样的互动。
独处的碎片时间
工作间隙、下班后或深夜打开，看看动态流，与熟悉的角色聊几句，让日常多一点生活气息。
想一起留下故事的时候
把熟悉的口头禅和生活习惯写进虚拟角色，围绕搭家、观察互动，获得可以分享的共同话题。

体验主线布置空间 → 创建角色 → 放入房间 → 观察互动 → 对话或投下事件 → 留下记忆与故事

02

项目说明

01

让空间安排相遇

布置空间也是在安排谁与谁共处。人物、家电与家具角色进入同一房间后，系统结合各自人设、状态和记忆生成反应，让空间操作能够带来新的故事。

SPACE · AGENTS · SHARED CONTEXT
02

让参与带来变化

用户可以找某个角色聊天，也可以投下“今天降温了”这样的神谕事件。模型结合当前情境生成角色回应与开场故事，各角色有自己的表达方式，也可以选择沉默。

PERSONA · DIALOGUE · ORACLE
03

让归家接上生活

事件时间线与记忆保存发生过的事，为之后的互动提供上下文。再次打开时，离线补演根据离开时长生成故事，在有限的模型调用下呈现生活的连续感。

EVENT LOG · MEMORY · CATCH-UP
